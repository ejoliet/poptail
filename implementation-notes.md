- 2026-08-11 phase2 DEVIATION: tail.Config now uses Poll:true (stat ~250ms) instead of fsnotify. Evidence: probe matrix under -race, 6/27 cycles lost the first line when the append landed in the window between tail reaching EOF and its watcher registering — the line then stays invisible until the NEXT write (indefinite on a quiet log). Poll:true = 0/27 failures. Also immune to filesystems where fsnotify silently no-ops (NFS, container mounts). Cost: one stat per 250ms, latency floor well inside the <2s gate. Initially misdiagnosed as a watcher leak — stop() was added (t.Stop()+t.Cleanup(), openSource now returns a stop func) but the probe showed failures with AND without stop, killing that hypothesis; stop() kept anyway as correct hygiene and used by main via defer.
