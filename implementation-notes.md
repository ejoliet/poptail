# implementation notes

- 2026-08-08 spike1: GO/NO-GO gate PASSED on phone over LTE — lines <2s, 15min watch, airplane-mode 30s resume with no missing lines, held on both default QUIC and forced http2 tunnel transport (`--protocol http2`; hidden flag, absent from `cloudflared tunnel --help` but valid). Note: `--http2-origin` is NOT the transport flag — it makes cloudflared speak HTTP/2 to the origin, which the plain net/http server (no h2c) rejects.
- 2026-08-08 spike1: trycloudflare quick tunnel buffered plain SSE — 0 bytes reached client until origin closed the response (verified: all 30 test ticks arrived in one burst at stream end; headers arrived in ~0.2s). Edge requests `Accept-Encoding: gzip` and holds uncompressed compressible bodies to compress them. Fix: origin sends `Content-Encoding: gzip` with a gzip flush per event — bytes then pass through live (verified 1s cadence end-to-end). Rejected alternatives: `Cache-Control: no-transform` (no effect), `Content-Encoding: identity` (no effect), 16KB padding (no effect), client HTTP/1.1 (no effect).
